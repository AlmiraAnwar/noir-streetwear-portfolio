NOIR STREETWEAR PORTFOLIO — CSC 337

HOW TO OPEN
1. Extract this ZIP file.
2. Open the NOIR_STREETWEAR_PORTFOLIO folder in Visual Studio Code.
3. Open index.html with Live Server (or open it in a browser).
4. Use the navigation to visit Home, Hobbies, Favourite Media and Contact.

IMPORTANT CUSTOMIZATION BEFORE SUBMISSION
- Replace the sample friend names and student IDs in hobbies.html and contact.html.
- Replace the sample email and phone number in contact.html.
- Review the five YouTube embeds in media.html and replace any video that does not match your favourite media.
- Add your own real social media screenshots/posts if your assignment requires actual posts. The current images are illustrative fashion inspiration images.
- The contact form is front-end only; it does not send messages to a server.
- Images, Google Fonts, YouTube embeds and Google Maps need an internet connection.
- Validate all four HTML files and css/style.css using the W3C validators before submitting.
- Make at least 10 meaningful GitHub commits as required by your assignment.

This project uses HTML and CSS only. No JavaScript is included.
